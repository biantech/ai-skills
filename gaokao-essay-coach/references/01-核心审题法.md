# 核心审题法

> 作文写砸，九成不是写不出来，而是**没审清楚**。审题是写作的地基。
> 地基歪了，楼越盖越高只会越偏。

本文件给出完整的审题方法论，Skill 在执行**审题诊断（M1）**、**立意打磨（M2）** 两种模式时必须先读本文件。

---

## 一、三立原则（写作前的地基）

### 1. 立概念：关键概念必须具体化

这是新高考作文最容易出问题的地方。题目材料里的关键词，你不能用它的"字典释义"去写，必须结合材料把它限定到**最精准的那个含义**。

**反例**：
- 题目谈"**最重要**"——学生把"最重要"当成"很关键的东西"来写，大谈"友谊最重要""健康最重要"。
- 题目谈"**选择的路**"——学生把"路"写成字面上的公路、乡间小道。

**正例**：
- "最重要"在题目里指的是**事物的优先级**，不是"所有关键事物"。写作时要紧紧围绕"优先级为什么会流变""为什么被反复强调的正是稀缺的"。
- "路"在题目里指的是**人生之路、成长之路**，不是物理意义上的路；"好走的路"指**平坦安逸、缺乏挑战**的人生选择，"选择的路"指**有挑战但符合本心**的道路。

**操作方法**：
1. 圈出题目里出现的每一个关键词
2. 对每一个关键词问：**在这则材料的语境里，它的含义被限定到哪一层？**
3. 把这一层含义**用自己的话写在草稿纸上**（不要只写在脑子里）
4. 后续写作，每次提到这个关键词时都要确认用的是这一层含义

---

### 2. 立事实：现象必须展开分析

作文材料里出现的**现象 / 事实**（包括案例、现象描述、社会观察），绝不能只是"引用一下"就带过。必须对它展开三个层次的分析：

- **这个现象为什么发生？**（原因层）
- **它反映了什么深层问题？**（本质层）
- **它带来了什么影响？** 或 **它合理 / 不合理吗？为什么？**（判断层）

**反例**：
```
许多人都偏爱"戏剧性的瞬间"。这种现象很常见。我们应该努力奋斗。
```
→ 把现象扔掉了，直接跳到结论。

**正例**：
```
人们对"戏剧性瞬间"的偏爱，指向人对更简单、更有趣地解释世界的追求，
仿佛只要能够解构生活的严肃、复杂，就可以躲避困难、享受愉悦。比起相信
万有引力理论发现之艰辛，人们更喜欢"苹果"与一瞬灵感，因为这可以将懒
于努力等待灵光乍现合理化；比起探查网络传闻的真相，人们更偏好被编排
出来吸引注意力的版本，因为这回应了人寻求精神刺激的天性。
```
→ 展开了"为什么"和"反映了什么"。

---

### 3. 立观点：所有观点必须证明

所有你在作文里亮出的观点——中心论点、分论点、段内小结论——都不能"光亮不证"。

**证明的三种方式**：
- **给理由**：讲清楚这个观点为什么成立（因果链）
- **给例子**：用人物、事件、数据来支撑（注意必须扣观点，不能堆积）
- **给分析**：把例子和观点"焊接"起来——指出例子里的哪些要素支撑了观点

**反例**（观点亮了没证）：
```
坚持是成功的秘诀。爱迪生发明电灯失败了上千次。马云创业历经艰辛。
所以我们要坚持。
```
→ 堆了例子，没有分析例子如何证明"坚持是成功的秘诀"。

**正例**：
```
坚持是"春蚕到死丝方尽"的奉献，以无私诠释人性独有的坚守。

君不见张桂梅扎根华坪山区，身患重病仍坚守讲台，用布满膏药的手托起
两千余名山村女孩的求学梦，这份坚持无关利益计算，只为改变命运；君
不见俞鸿儒院士潜心风洞研究六十余载，九十高龄仍坚守科研一线，以毕
生心血铸就"国之重器"，这份坚持超越个人得失，只为托举中国航天腾飞。

此等坚持之所以成就，在于他们都有一个共同点：把"别人的事"变成了
"自己的事"——把山区女孩的命运、把国家的航天事业，装进自己的一生。
坚持的真正内核，不是咬牙硬撑的意志力，而是把意义锚定在自身之外的
那份笃定。
```
→ 观点 + 素材 + 分析 + 小结，每一步都在证明。

## 二、三叩审题法（完整执行流程）

拿到一道作文题，按以下三叩依次执行：

### 第一叩：叩问材料

**做什么**：把材料本身吃透。

**核心问题清单**：
1. 材料围绕什么话题展开？——**用一句话写出来**
2. 材料呈现的是一个事实 / 现象，还是一个观点 / 判断，还是两者都有？
3. 如果有多句话，它们之间是什么关系？
   - 并列（A 和 B 同等重要）
   - 递进（A 之后 B 更深入）
   - 转折（A 但是 B）
   - 因果（因为 A 所以 B）
   - 对立（A 与 B 互相否定）
   - 辩证（A 和 B 看似矛盾，实则统一）
4. 这个现象 / 观点发生在什么情境（背景、场合、条件）下？
5. 涉及哪些人 / 要素？他们之间是什么关系？**主要的人 / 要素是谁？**
6. 为什么会出现这种现象 / 产生这种观点？

**关键技巧**：
- 材料是多句话时，**不能只抓前半句**，一定要梳理每一句及其相互关系
- 典型陷阱：前半句是"现象"，后半句是"观点"，学生只分析现象，不证明观点

### 第二叩：叩问提示语

**做什么**：把命题者布置的所有"任务"逐一列出来。

**核心问题清单**：
1. 有没有提示语？（一般以"以上材料引发了你怎样的联想和思考"这类句式出现）
2. 命题者布置了哪些**任务**？
   - 身份：以什么身份写？（青年？学生？普通人？）
   - 对象：写给谁看？（同龄人？社会大众？特定人群？）
   - 场景：在什么场合用？（演讲？书信？作文？）
   - 目的：写作意图是什么？（呼吁？说明？反思？）
   - 主题：核心要谈什么？
3. 有没有"联想和思考"这类**发散指令**？
   - 有 → 必须调动知识储备、联想古今中外、扩展到当代现实
   - 没有 → 更偏向于就材料本身做严密分析
4. 有没有"**结合材料**"这类**收敛指令**？
   - 有 → 全文不能脱离材料
5. 有没有"**自拟标题**""**自选角度**"这类**自由度指令**？

**关键技巧**：
- 把所有提示语任务**在草稿纸上列成清单**，每完成一项打勾
- 漏了一个提示，作文可能直接降一个档

### 第三叩：叩问试题（自问自答立意 → 骨架 → 细节）

**做什么**：根据前两叩的结论，把自己的写作方案完整定下来。

**核心问题清单**：
1. 我的**立意**是什么？（用一句话写出来，不超过 25 字）
2. 立意的**中心句**怎么写？（将在开头段亮出的那一句）
3. 我准备设几个**分论点**？
   - 新高考议论文一般三个主体段、三个分论点
   - 四个也可以，但要注意字数控制（单段 200 字左右）
4. 分论点之间是什么关系？
   - **层进式**（从浅到深：是什么 → 为什么 → 怎么办 / 从个体 → 到社会 → 到国家）⭐ 推荐
   - **对照式**（正面与反面 / 古与今 / 个体与集体）
   - **辩证式**（A 是对的 + 但不能忽略 B + 要把 A 和 B 结合起来）
5. 每个分论点要**证明什么**？用**什么素材**？
6. **开头**怎么写？（引材料 + 亮中心句，不超过 150 字）
7. **结尾**怎么收？（引一句 + 回扣开头 + 呼吁青年）

## 三、常见审题陷阱

| 陷阱 | 典型表现 | 后果 | 对策 |
|---|---|---|---|
| **关键概念悬空** | 把"最重要"写成"很关键的事" | 全文空泛、不扣材料 | 用三立原则的第 1 条具体化 |
| **只分析一半** | 两句材料，只抓第一句 | 立意不全面 | 在叩问材料时列清两句关系 |
| **观点亮了不证** | 全文重复中心句 | 论证虚空 | 每段按五句一段法证明 |
| **脱离"怎么办"** | 只谈是什么、为什么 | 缺当代关怀、层次浅 | 主体段三必须落到"怎么办" |
| **套作痕迹重** | 堆背过的名言、套固定结构 | 阅卷老师一眼识破 | 每道题重新审、不用万能模板 |
| **忽略提示语任务** | 没写身份 / 对象 / 场景 | 任务性作文直接降档 | 在叩问提示语时打勾清单 |
| **材料概述过长** | 开头花 200 字复述材料 | 占掉论证篇幅 | 开头引材料不超过 50 字，一笔带过 |

## 四、审题输出模板（Skill 在 M1 模式下使用）

当学生触发**审题诊断**模式时，按以下模板输出：

```markdown
## 审题报告：[作文题简称]

### 一、材料核心
- **核心话题**：[一句话]
- **材料结构**：
  - 第 1 句：[摘抄或概括]——这是 [事实/现象/观点/判断]
  - 第 2 句：[摘抄或概括]——这是 [事实/现象/观点/判断]
  - 两者关系：[并列/递进/转折/因果/对立/辩证]，因为 [解释]

### 二、关键概念具体化
| 关键词 | 在本题中的具体含义 | 容易犯的误解 |
|---|---|---|
| [关键词 A] | ... | ... |
| [关键词 B] | ... | ... |

### 三、提示语任务清单
- [ ] 身份限定：[有/无]，具体是 [...]
- [ ] 对象限定：[有/无]，具体是 [...]
- [ ] 文体要求：[...]

（同上结构）

#### 立意 3：[标题化表达]
```

## 五、教学要点（Skill 使用本文件的边界提示）

1. **不要跳过叩问材料直接给立意**——否则学生学不到方法
2. **不要只给一个立意**——给三个，并说清楚各自难度与特色，让学生选
3. **不要用"万能立意"**——每道题都重新审，拒绝"无论什么题都能写的立意"
4. **要把"为什么这样审"讲给学生**——说清思路，而不只是给结果
5. **涉及具体人物或事件的时候**，只用 `resources/01-人物素材库.md` 里有的——不在库里的要标注"需核实"
