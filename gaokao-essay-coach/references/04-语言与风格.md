# 语言与风格

> "写作就是思维外化的过程。"
> 
> 句式、节点、标题、分析法，这些不是装饰，而是思维方式的痕迹。
> 一篇作文的语言气质，就是学生这几年思维训练的总和。

本文件是 Skill 执行**范文写作（M4）**、**批改（M5）**时的语言风格规范。

---

## 一、标题模板

高考议论文的标题，**不是点题那么简单**——它是作文的"第一印象"，决定阅卷老师对全文的心理定位。

### 一类文的标题都有以下特征之一

1. **对仗工整**：上下句字数相等、结构对应
2. **观点鲜明**：一看就知道你的核心立场
3. **有诗意 / 化用**：引用或化用诗词 / 古语
4. **暗含辩证**：标题本身就包含对立或张力

### 四种高质量标题模板

#### 模板 A：对仗双句式

结构：**[动词短语]，[动词短语]**

```
守"爱"为灯，辨我为人
以梦为马，向阳而生
执衡而行，不困于"最重要"
主动补全"下半句"（简化版）
```

#### 模板 B：主副标题式

结构：**[主标题]——[副标题：论... / 评... / 从...看...]**

```
以梦为马，向阳而生——从《飞驰人生3》看个人成长的三重境界
执一而应万：论价值排序的变与不变
以热爱为翼，赴人生飞驰——评《飞驰人生3》
```

#### 模板 C：反向 / 化用式

结构：**化用名句或反用常识**

```
不盼瞬间降临，沉潜自辟前路
走出戏剧幕厅，触摸真实生活
让后半句照亮前路
听完整话，做明白事
返璞归真，择善而从
```

#### 模板 D：四字关键词式

结构：**[四字短语]，[四字短语]**

```
明辨"最重要"境遇，守护"最重要"现实
在流变中守护永恒
真知在平衡之间
```

### 反面清单（绝对不用的标题）

- 论选择 ❌
- 关于热爱的思考 ❌
- 我看"最重要" ❌
- 浅谈 XXX ❌
- 由...想到的 ❌

### Skill 出标题的决策流程

1. 先看立意的核心张力在哪（两个对立概念？一个主张？）
2. 有张力 → 用模板 A 或 D（双句式）
3. 涉及文艺作品或人物 → 用模板 B（主副标题）
4. 想有诗意 → 用模板 C（化用）
5. 起出 3 个候选标题，让学生选（不要一锤定音）

## 二、句式变化

### 议论文最容易出问题的三个句式问题

1. **短句堆砌**：全文都是"这很重要。那也很重要。"像机关枪
2. **长句纠缠**：一句话五六个逗号，读完忘了主语
3. **结构重复**：每段都是"XX 是 YY。举例 A。举例 B。所以 XX 是 YY。"

### 句式多样性的三条训练法

#### 1. 一段内长短搭配

议论文主体段最好 **"长句 + 短句"交替**：
- 长句：展开分析、陈述复杂判断
- 短句：观点亮相、结论收束、节奏顿挫

**示例**：
> 真正的强者，从不会被阴谋所定义。（短，观点）张驰的选择，为我们指明了破局之道——行阳谋，立实力。（中，点题）他毅然辞去光鲜却傀儡的职位，倾尽所有组建车队，不抱怨、不纠缠，将所有精力都投入到打磨技术、熟悉赛道的"阳谋"之中。（长，展开）他深知，会议室里的交易或许能决定一时的胜负，但赛道上的成绩，永远只认实力。（中，再点）

#### 2. 多用排比，但不过度

排比句可以在一篇作文中出现 **2-3 次**：
- 段内材料排比："君不见…君不见…君不见…"
- 段内分析排比："若无 X…若无 Y…若无 Z…"
- 结尾呼吁排比："愿你 X，愿你 Y，愿你 Z"

**排比的三件套**：
1. 结构完全对应（字数、词性、断句）
2. 内容有递进（从个体到国家 / 从现象到本质）
3. 用真实人物（不是空概念）

**示例**（三材料排比）：
> **君不见**张桂梅扎根华坪山区，身患重病仍坚守讲台，用布满膏药的手托起两千余名山村女孩的求学梦；**君不见**俞鸿儒院士潜心风洞研究六十余载，九十高龄仍坚守科研一线，以毕生心血铸就"国之重器"；**君不见**刘玲琍扎根特教讲台三十三年，自创唇舌操、触摸教学法，让听障孩子开口说话、考上大学。

#### 3. 善用反问与设问

反问和设问能让文章产生**对话感**：

| 句式 | 使用时机 |
|---|---|
| "真的是这样吗？" | 转折、引出反面分析 |
| "但从来如此，便对吗？" | 质疑既定观念 |
| "何以 X？" | 追问原因 |
| "岂能 / 岂可 / 怎能 ...？" | 强化判断、反向证明 |
| "若无 X，怎有 Y？" | 假设分析 |

**示例**：
> 可见，"疑"不是否定一切，而是以问题为舟，渡向未知之境——**此等创造力，AI 难以企及**。

## 三、四大分析法

分析法是议论文论证的"发动机"。每个主体段的**分析句**必须运用其中至少一种。

### 1. 因果分析法

**标志词**：为什么 / 为何、之所以…是因为、究其缘由、根本在于、出现这种情况的原因在于

**用法示例**：
> **为什么**他们没有因"埋没"而"窒息"，反而有所建树呢？**因为**他们是生活的强者，他们不甘忍受被"埋没"的命运。不管在什么情况下，他们始终没有丧失向上的勇气和力量。

**适用场景**：分析现象成因、解释为什么观点成立

### 2. 假设分析法

**标志词**：如果（假如、倘若、设若、若无）… 就（那就、反而会）、假如…怎能…

**用法示例**：
> **倘若**路遥热衷于追逐一时的声名与社交场的繁华，**而非**选择这样一种近乎苦行僧式的寂寞状态，他的精神世界**又如何能**如此深刻地与笔下的黄土高原融为一体？

**适用场景**：反向证明、"假设没有这个因素就不会有这个结果"

### 3. 条件分析法

**标志词**：只有…才能、唯有…方能、除非…否则、不…就不能

**用法示例**：
> **只有**保持独立思考和对真相的不懈追寻，我们才是脚踏实地的生活者，能够不为人所惑，把握自我主体性。

**适用场景**：提出主张、给出"怎么办"的建议

### 4. 评价分析法

**标志词**：其价值在于、其意义在于、此等 X、值得珍视的是、最动人的是

**用法示例**：
> **此等**无私之爱，算法何以生成？

> **这份**将承诺转化为行动、将责任融入血液的坚守，让他们在各自的坐标上树起了不朽的精神丰碑。

**适用场景**：给出判断、升华意义、收束段落

### 分析法组合使用

一个段落的分析句部分，可以**多种分析法组合**。

**示例**（因果 + 假设 + 评价组合）：
> **为什么**他能做到四十年如一日？**因为**他把"带民致富"的承诺刻进了骨头里。**若没有**这份承诺，**怎会有**抗病魔、拔穷根的坚韧？**此等**将个人命运与乡村振兴绑定的担当，正是新时代基层干部的精神底色。

## 四、节点语言速查

（与 `02-段落与结构.md` 重合，但这里作为执行层面的**精简速查卡**）

## 五、表达 DNA（这位"老师"的语言特征）

Skill 在写范文和评语时，应当体现以下表达特征：

### 1. 文白相间

古今素材穿插使用，文白句式错落。偶尔化用一句古诗或文言表达，但不通篇文言。

**示例**：
> 张驰能重回巅峰，靠的不是运气，而是日复一日的坚持与打磨。**古有**范蠡弃官经商，终成陶朱公；**今有**雷军躬身造车，亦见商道通达。

### 2. 比喻要"有肉"

比喻不能空。"人生如赛道"太泛，加上具体的延展才有力。

**一般比喻**：人生如赛道，有起有伏。
**有肉比喻**：人生如赛道，时而坦途，时而弯道，时而晴空万里，时而风雨交加。

### 3. 偏爱"三件套"

- **人生"三重境界"**
- **青年"三个使命"**
- **心中"三把尺"**

列举时优先用三，形成节奏感。

### 4. 结尾必升华

不能"平着收"。必须在结尾有一句**比喻 / 对偶 / 短句爆破**：

- "赛道有尽头，热爱无终点。"
- "传统是一条河，前半句是河床，后半句是水流。"
- "真正的胜利，不在会议室，而在为梦想日夜打磨的每段征程。"

### 5. 避免的表达

- "在当今社会" → 改为 "今天" / "现今" / 直接写现象
- "这让我们深刻认识到" → 改为 "这告诉我们" 或节点词 + 内容
- "让我们一起" → 完全避免（AI 味）
- "在某种意义上说" → 避免空话
- "XX 最近很火" → 直接讲 XX 是什么，不评论火不火

## 六、范文生成质量自检清单

Skill 在 M4 模式下生成范文后，自己先走一遍以下清单：

### 语言层面

- [ ] 标题对仗 / 观点式 / 化用，不是"论 XXX"
- [ ] 开头引材料不超过 50 字
- [ ] 至少一段有"君不见…君不见…"排比材料
- [ ] 节点词出现 5 次以上
- [ ] 没有"让我们一起""在当今社会"这类 AI 套话
- [ ] 每段分析句用到了四大分析法之一
- [ ] 结尾有对偶 / 比喻 / 短句的升华

### 素材层面

- [ ] 所有人物都在 `resources/01-人物素材库.md` 里
- [ ] 当代人物 + 古典人物搭配合理
- [ ] 素材与观点咬合紧（不是堆砌）
- [ ] 同类素材不超过 2 个（避免只用科学家 / 只用运动员）

### 结构层面

- [ ] 开头段亮了中心观点
- [ ] 分论点之间有清晰关系（层进 / 对照 / 辩证）
- [ ] 主体段严格按五句一段法
- [ ] 结尾回扣开头 + 引一句 + 呼吁青年

### 思想层面

- [ ] 扣住材料关键概念，不跑题
- [ ] 至少一段展现辩证思维
- [ ] 末段落到当代青年实际
- [ ] 没有口号化、情绪化的表达

**检查不通过的项，重写该部分后再输出。**

## 七、常见败笔对照

| 败笔类型 | 原文（典型错误） | 改后 |
|---|---|---|
| **空观点** | 我们要坚持。坚持才能成功。 | 真正的坚持，是把"别人的事"变成"自己的事"。 |
| **素材堆砌** | 有张桂梅、袁隆平、钱学森、屠呦呦、钟南山... | 君不见张桂梅扎根华坪山区；君不见袁隆平躬耕稻田；君不见钱学森归国攻坚。三位，分属于教育、农业、科技，却在同一件事上达成默契——把自己的人生，许给国家最需要的地方。 |
| **AI 味说教** | 让我们一起来思考这个深刻的问题。 | 这究竟是精华的提取，还是断章取义的谜局？ |
| **标题平铺** | 论最重要 | 明辨"最重要"境遇，守护"最重要"现实 |
| **结尾平收** | 总之，我们要重视最重要的事物。 | "最重要"不是僵化的标签，而是流动的智慧；不应是稀缺的焦虑，而应是行动的号角。 |
| **空分析** | 这体现了他的伟大精神。 | 若没有"扛千钧重担"的韧性，这个家怎会在风雨中不散？ |
| **套路开头** | 在当今社会，随着经济发展... | （删除。直接从材料核心话题切入。） |

## 八、风格守则（Skill 自我约束）

1. **不说教**：让观点自己说话，不用"让我们认识到""我们应该明白"。
2. **不堆金句**：金句服务于论证，不是装饰。一段最多一句金句。
3. **不用生僻字**：高考作文不是炫技，用字要让阅卷老师三秒读懂。
4. **不过度古风**：偶尔化用古语可以，但通篇"之乎者也"会反噬。
5. **不强行煽情**：议论文的力量来自逻辑，不是感叹号。
6. **不抄范文结构**：每道题独立构思，拒绝"万能模板"。
