> 
> 展示 Skill 在 M3（提纲生成）和 M4（范文写作）模式下的完整输出。

## 对话样本 · 第一轮 · 提纲生成

### 学生输入

> 老师，上面那道"最重要"的题，我选立意 1"执一而应万"，帮我列一份提纲吧。

---

### Skill 输出（按 M3 · 提纲生成模式）

```markdown
## 提纲：执一而应万——在流变中守护永恒

### 标题候选（你可以挑一个）

1. 执一而应万：在流变中守护永恒 ⭐ 推荐
2. 承认流变，锚定稀缺
3. 万变的"最重要"，不变的行动

### 开头段（约 150 字）

**任务**：引材料 + 点张力 + 亮观点

**思路**：
- 先引第一句——点出"最重要"的**流变性**
- 再引第二句——点出"反复宣称"的**悖论性**
- 最后亮观点：**真正的智慧，在于在流变中锚定价值，在稀缺中用行动守护**

**结构示例**：
> "最重要"一词，常被我们用以确立事物的优先级。然而细察之下……。更耐人寻味的是……。这二者之间的张力提醒我们：[中心观点]

### 主体段 1：承认流变（层进第一步：合理性层面）

**分论点**：**"最重要"随立场境遇而变，是现实需求的动态适配，自有其天然合理性。**

**五句结构**：
- **观点句**：直接亮出上述分论点
- **阐释句**：说明"为什么这种流变合理"——主体位置不同、境遇阶段不同，必然带来不同的优先级判断
- **材料句**：选 2-3 个素材做"君不见"排比
  - 推荐组合：**陶渊明**（选择自由 > 官职） + **苏轼**（贬谪后选旷达 > 致君尧舜） + **司马迁**（宫刑后选文脉 > 出人头地）
- **分析句**：用**因果分析**——他们的"最重要"变化，不是价值虚无，而是对境遇的诚实回应
- **结论句**："可见，承认'最重要'的流变，是对人性复杂与现实多元的尊重。"

**推荐素材（按顺序）**：
- 陶渊明 `resources/01 · 古典人物`
- 苏轼 `resources/01 · 古典人物`
- 司马迁 `resources/01 · 古典人物`

**推荐分析法**：因果 + 假设

### 主体段 2：洞察悖论（层进第二步：本质层面）

**分论点**：**"最重要"的反复宣称，恰是对其稀缺脆弱的反向证明。**

**五句结构**：
- **观点句**：亮出上述分论点
- **阐释句**：稀缺催生重视，脆弱倒逼强调——我们高喊什么，往往恰恰因为缺少什么
- **材料句**：
  - **林觉民《与妻书》**（反复倾诉"至爱"，正因为这爱即将永别，太脆弱）
  - **当代社会反复强调"诚信""健康"**（因为稀缺才被反复强调）
- **分析句**：用**假设分析** + **反问**——倘若这份爱早已安稳无虞，又怎会在信纸上反复泣血？
- **结论句**："**反复宣称**从来不是坚固的证据，而是脆弱的自白。"

**推荐素材**：
- 林觉民 `resources/01 · 古典人物`
- 陶渊明（《归去来兮辞》里"田园将芜胡不归"也是反复呼唤 → 自由的稀缺）
- 当代社会现象：家长不断告诫"成绩最重要"=> 教育内卷背景下对成绩的焦虑

**推荐分析法**：假设 + 评价

### 主体段 3：行动守护（层进第三步：当代青年层面）

**分论点**：**作为青年，当以"内核守一"应对"表象万变"，以"行动填补"治愈"语言焦虑"。**

**五句结构**：
- **观点句**：亮出上述分论点（或引一句扣合的古语作开头，如"君子务本，本立而道生"）
- **阐释句**：说明"内核守一"指什么（人格尊严、精神完整）、"行动填补"指什么（用实干代替口号）
- **材料句**：
  - **袁隆平**（从未说过"吃饭最重要"，却用一辈子让中国人吃饱）
  - **张桂梅**（从未挂"教育最重要"标语，用布满膏药的手托起 2000 女孩）
  - **陆鸿**（残疾人创业，不靠"自强最重要"的口号，靠一家真正的工厂）
- **分析句**：用**评价分析** + **对比**——"此等守护，非语言所能完成；此等完整，非宣称所能抵达"
- **结论句**：回扣中心观点——"这就是执一而应万的真正含义"

**推荐素材**：
- 袁隆平 `resources/01`
- 张桂梅 `resources/01 · 感动中国`
- 陆鸿 `resources/01 · 感动中国`

**推荐分析法**：评价 + 对比

### 结尾段（约 100 字）

**任务**：引一句 + 回扣开头 + 呼吁青年

**思路**：
- 引用"吾道一以贯之"或"千江有水千江月"
- 回扣"流变 + 守护"两个关键词
- 呼吁青年

**结构示例**：
> "[引一句]"。回望材料——[扣合中心观点]。愿我辈青年，[动作 1]，[动作 2]，让"最重要"不再是摇摆的标签，而是行动的印记。

### 提纲小结

| 段 | 核心动作 | 关键素材 |
|---|---|---|
| 开头 | 引 + 点 + 亮 | — |
| 主体 1 | 承认流变的合理性 | 陶渊明、苏轼、司马迁 |
| 主体 2 | 洞察反复宣称的悖论 | 林觉民、当代社会 |
| 主体 3 | 行动守护的当代路径 | 袁隆平、张桂梅、陆鸿 |
| 结尾 | 引 + 回扣 + 呼吁 | 吾道一以贯之 / 千江有水 |

### 下一步

你可以：
- 按这份提纲自己写一篇（推荐，因为写的过程就是思考的过程）
- 或对我说"**按这份提纲写一篇范文给我看**"，我会写一篇完整的对照范文
```

## 对话样本 · 第二轮 · 范文写作

### 学生输入

> 老师，按这份提纲写一篇范文给我看看，我想参照一下。

---

### Skill 输出（按 M4 · 范文写作模式）

```markdown
## 范文

### 执一而应万：在流变中守护永恒

"最重要"一词，常被我们用以确立事物的优先级。然而细察之下，这看似坚定的判断，却如流水般随立场与境遇变迁。更耐人寻味的是，当我们不断宣称某事物"最重要"时，恰恰暴露了它在现实中的稀缺与脆弱。这二者之间的张力提醒我们：真正的智慧，不在于找到一个永恒不变的"最重要"并奉为圭臬，而在于在流变中锚定价值，在稀缺中用行动守护。

"最重要"随立场境遇而变，自有其天然的合理性。人的位置不同、处境不同，对"优先级"的判断自然殊异——这不是价值的摇摆，而是生命经验的诚实沉淀。**君不见**陶渊明在"田园将芜胡不归"的呼唤中，把"自由"置于官职之上，挂印而去；**君不见**苏轼在乌台诗案后，把"保全生命与民生关怀"置于"致君尧舜"的理想之上，唱出"一蓑烟雨任平生"；**君不见**司马迁遭受宫刑之后，昔日功名崩塌，却把"完成《史记》、传承文脉"作为生命的新坐标，从此"究天人之际，通古今之变"。三位先贤的"最重要"，都在境遇的骤变中重新排列，然而他们并未因此走向虚无——相反，正是这份对境遇的诚实回应，让他们的生命反而变得更加厚重。**可见**，承认"最重要"的流变，是对人性复杂与现实多元的尊重，不是放弃坚守，而是更深层的清醒。

然而，**更主要的问题是**：当我们不断宣称"某事物最重要"时，恰恰在反向证明它的稀缺与脆弱。稀缺催生重视，脆弱倒逼强调——我们高喊什么，往往恰恰因为缺少什么。《与妻书》里，林觉民在起义前夜写给陈意映的绝笔信中，一遍又一遍地倾诉"吾至爱汝"——**倘若**这份爱早已安稳无虞，**又怎会**在信纸上反复泣血？这份反复本身，就是这份爱在国难当头时的脆弱自白。放眼当下，社会不断强调"诚信最重要"，恰是因为诚信在日益稀缺；家长不断告诫"健康最重要"，往往是在身体亮起红灯之后。**归根到底**，那些无需刻意强调的"最重要"——如阳光、空气——正因常态供给、不缺不脆，才不必时时挂在嘴边。由此可见，"**反复宣称**"从来不是坚固的证据，而是脆弱的自白。

**然而**，看清了流变与稀缺的真相，青年的出路**究竟在何方**？**"君子务本，本立而道生"**——真正的答案在于：以**内核守一**应对**表象万变**，以**行动填补**治愈**语言焦虑**。袁隆平从未在讲台上反复强调"吃饭最重要"，却用六十年躬耕稻田让中国人不再挨饿——他的"最重要"不在口号里，而在田埂上；张桂梅从未在校门口挂"教育最重要"的标语，却用布满膏药的手托起两千余名山区女孩的求学梦——她的"最重要"不在言辞中，而在那一双双走出大山的眼睛里；陆鸿从不说"自强最重要"，却把曾被叫"傻子"的自己变成残疾人创业基地的带头人——他的"最重要"不在宣言上，而在工厂的一台台机器里。**此等守护，非语言所能完成；此等完整，非宣称所能抵达**。反观那些只停留在"XX 最重要"口号中的我们，是否也该向他们学一学——把嘴上的重视，换成脚下的迈进。

"**吾道一以贯之**"，孔子此语，道破了"万变中不变"的真谛。"最重要"的流变，是对境遇的诚实；"反复宣称"的焦虑，是对稀缺的警醒。真正的智慧，是在流变中锚定价值的内核，在稀缺中以行动替代喧嚣。愿我辈青年，既不困于"标准答案"的教条，也不困于"反复宣讲"的焦虑；既有承认流变的清醒，也有守护内核的坚定。让"最重要"不再是挂在嘴边的标签，而是落到脚下的印记——如此，方能在变动不居的世界里，写下属于这一代青年的价值篇章。

---

（全文约 980 字）

---

## 结构透视

| 段 | 功能 | 核心动作 | 用到的技巧 |
|---|---|---|---|
| 开头 | 引材料 + 亮观点 | 把两句话的张力点出来，直接亮出中心观点 | 现象切入 + 问题提出 + 观点回应 |
| 主体 1 | 承认流变合理 | 三人"君不见"排比 + 因果分析 | 五句一段法；排比材料句；节点词"可见" |
| 主体 2 | 洞察悖论本质 | 林觉民 + 当代社会 + 假设分析 | 反问"又怎会"；节点词"更主要的问题是""归根到底""由此可见" |
| 主体 3 | 行动守护路径 | 袁、张、陆三人排比 + 评价分析 | 节点词"然而""究竟在何方"；"此等…非…所能" |
| 结尾 | 引用 + 回扣 + 呼吁 | 孔子 + 回扣"流变/稀缺" + 对青年的呼吁 | 引一句 + 对偶收束 |

## 语言风格说明

本文**刻意运用了以下风格特征**，供学生对照参考：

1. **节点词使用**：全文用了"君不见""可见""更主要的问题是""倘若""又怎会""归根到底""由此可见""然而""究竟""此等""反观"等 **11 处**节点词，每段至少 2 个。
2. **排比句**：第 2 段"君不见…君不见…君不见…"、第 4 段"袁隆平…张桂梅…陆鸿…"两处三人排比，构建气势。
3. **假设分析**：第 3 段"倘若这份爱早已安稳无虞，又怎会…"。
4. **评价分析**：第 4 段"此等守护，非语言所能完成；此等完整，非宣称所能抵达"。
5. **对偶收束**：结尾"既不困于教条，也不困于焦虑；既有承认流变的清醒，也有守护内核的坚定"；以及"不再是挂在嘴边的标签，而是落到脚下的印记"。
6. **标题对仗**：主标题"执一而应万"对副标题"在流变中守护永恒"。

## 写作提醒

这篇范文**仅供参考不要抄袭**——
- 抄原文到考场 = 套作，会被直接判低分
- 真正的学习是：**看懂它的骨架，理解它的动作，然后用自己的语言按同样的骨架再写一遍**
- 建议你先不看这篇范文，按提纲自己写一版，写完再对照——才知道自己弱在哪

### 下一步

如果你按提纲自己写了一版，欢迎发给我，我会按"批改模式"给你打分 + 具体建议。
```

## 附录 · 这个示例展示了什么

本示例演示了 Skill 在提纲生成与范文写作时应当遵守的**八条纪律**：

### 提纲阶段（M3）

1. **给出 2-3 个标题候选**，不是一锤定音
2. **开头 / 主体段 / 结尾**都说清楚"做什么""怎么做"
3. **主体段严格按五句一段法**给出五句的内容指引
4. **推荐素材必须在 `resources/01` 里查证过**，并标注出处
5. **推荐分析法**，让学生知道每段用什么"动作"

### 范文阶段（M4）

6. **范文严格按提纲写**，字数 850–1000 字
7. **附上"结构透视"**，让学生看懂骨架
8. **主动提醒"不要抄袭"**，给出正确的参考用法

## 这个示例没展示（但 Skill 应做的）

- 学生要求**"再写一篇，用不同的素材"**时，应当按同样的骨架换素材重写
- 学生要求**"这一段我看不懂，拆开讲一下"**时，应把段落拆解成五句，逐句解释
- 学生要求**"这句话能不能换个说法"**时，应给出 2-3 个改写版本
- 学生要求**"这篇范文多少分"**时，应按批改标准自评（一般一类文 55-58 分）
