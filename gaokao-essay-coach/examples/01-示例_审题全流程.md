# 示例 · 审题全流程

> 这是一个完整的"学生发题 → Skill 审题 → 学生选立意 → Skill 打磨立意"的走查。
> 
> 目的是让看完这份文件的人——无论是 Skill 本身、使用 Skill 的学生、还是借鉴本 Skill 的开发者——都能直观理解**这位"老师"的审题节奏**。

---

## 对话样本

### 学生输入

> 老师，帮我审一下这道作文题：
> 
> 阅读下面的材料，根据要求写作。（60 分）
> 
> "最重要"一词，常被我们用以确立事物的优先级，然而，对"最重要"的判断往往随立场、境遇而改变。还有人指出，当我们不断宣称某事物"最重要"时，正暴露了它在现实中的稀缺与脆弱。
> 
> 以上材料引发了你怎样的联想和思考？请写一篇文章。
> 
> 要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不得泄露个人信息；不少于 800 字。

---

### Skill 输出（按 M1 · 审题诊断模式）

```markdown
## 审题报告：关于"最重要"的流变与悖论

### 一、材料核心

**核心话题**：对"最重要"的判断（价值排序）

**材料结构**：

- 第 1 句："'最重要'一词，常被我们用以确立事物的优先级"——这是**陈述一个事实**（我们的语言习惯）；"然而……随立场、境遇而改变"——这是一个**观察 / 判断**。
- 第 2 句："还有人指出……正暴露了它在现实中的稀缺与脆弱"——这是第二个**观察 / 判断**。

**两者关系**：**递进 + 辩证**。
- 第 1 句谈"最重要"的**流变性**（同一主体因立场境遇不同，判断不同）
- 第 2 句谈"最重要"被**反复宣称的悖论**（越强调越稀缺）
- 两者同指"最重要"这一概念，但从**不同角度**揭示其特点——一个从主体视角，一个从宣称现象。

### 二、关键概念具体化

| 关键词 | 在本题中的具体含义 | 容易犯的误解 |
|---|---|---|
| 最重要 | **优先级最高的事物**（命题者已明确界定为"优先级"）| 误解为"很重要"、"所有关键事物" |
| 立场 | 主体所处的位置、视角、身份 | 泛化为"立场正不正确" |
| 境遇 | 主体所处的处境、阶段、时代背景 | 泛化为"命运" |
| 稀缺 | 现实中缺乏、不足 | 泛化为"珍贵" |
| 脆弱 | 容易被破坏、难以长久持有 | 泛化为"感情上的脆弱" |
| 宣称 | 用语言反复强调 | 忽略其"反复"的行为特征 |

### 三、提示语任务清单

- [x] **身份限定**：无（默认高中生视角）
- [x] **对象限定**：无（默认广义读者）
- [x] **文体要求**："明确文体"——议论文为最优选择
- [x] **字数要求**：≥800 字
- [x] **"联想和思考"发散指令**：有——必须调动古今中外的联想、扩展到当代现实
- [x] **"结合材料"收敛指令**：有（"以上材料引发了你怎样的联想和思考"）——不能脱离材料

### 四、立意建议（3 选 1）

#### 立意 1：执一而应万——在流变中守护永恒 ⭐ 推荐

- **切入角度**：辩证式（承认变 + 守住不变 + 二者统一）
- **中心句**：真正的智慧，不在于找到一个永恒不变的"最重要"并奉为圭臬，而在于在变动中锚定价值、在稀缺中坚守行动。
- **分论点骨架**：
  1. "最重要"随立场境遇而变，是现实需求的动态适配，具备天然合理性
  2. "最重要"被反复宣称，恰是对其稀缺脆弱的反向证明
  3. 作为青年，当以"内核守一"应对"表象万变"，以"行动填补"治愈"语言焦虑"
- **素材方向**：
  - 段 1：陶渊明 / 苏轼 / 史铁生（境遇变化 → 价值重置）
  - 段 2：屈原 / 张桂梅 / 林觉民（反复强调背后的稀缺）
  - 段 3：袁隆平 / 陆鸿 / 当代青年实际
- **难度与特色**：**有挑战但出彩**——辩证思维展现得好容易拿一类文；处理不好容易三段平行、无递进
- **推荐原因**：题目本身是辩证结构，这个立意最扣题

#### 立意 2："最重要"从不是唯一答案

- **切入角度**：层进式
- **中心句**："最重要"从不是僵化的标签，而是流动的智慧；不应是稀缺的焦虑，而应是行动的号角。
- **分论点骨架**：
  1. "最重要"是主体与情境互动的产物（"是什么"）
  2. 反复宣称"最重要"暴露其稀缺的社会心理（"为什么"）
  3. 当代青年应构建多元价值、以行动代替强调（"怎么办"）
- **素材方向**：
  - 段 1：蔺相如 vs 廉颇 / 司马迁 / 求学者 vs 写作者
  - 段 2：林觉民《与妻书》 / 社会对"健康""诚信"的强调
  - 段 3：袁隆平 / 陆鸿 / 杨宁（用行动治愈稀缺）
- **难度与特色**：**中等**——思路稳，但不容易出彩，容易写成"是什么 + 为什么 + 怎么办"的标准模板
- **推荐原因**：保守稳妥

#### 立意 3：守住你的"最重要"——脆弱之中的顽强

- **切入角度**：对照式（流动的"最重要" vs 稳定的"最重要"）
- **中心句**：有些"最重要"因立场境遇而变，这是合理的；但还有些"最重要"代表普适价值，正因稀缺才需我们守护。
- **分论点骨架**：
  1. 个体之"最重要"随阶段与立场分化，具备流动性（求学者、写作者、国家战略）
  2. 普适价值之"最重要"因稀缺而显得脆弱（和平、自由、道德、公平）
  3. 破局在你我手中——看见脆弱、守护顽强
- **素材方向**：
  - 段 1：村上春树 / 职业选择 / 国家五年规划
  - 段 2：伊朗小学、战争背景 / 张桂梅、吴孟超（守护）
  - 段 3：西西弗斯式的坚守 / 青年的顽强
- **难度与特色**：**偏抒情 / 有诗意**——容易出彩也容易失控；适合语言功底较好的学生
- **推荐原因**：文学性较强，有独特视角

### 五、常见写偏的陷阱

1. **把"最重要"等同于"很关键"**：只谈"友谊最重要""健康最重要"，完全脱离材料的"优先级 + 流变 + 稀缺"核心
2. **只抓一句**：只写"最重要随境遇而变"或只写"反复宣称暴露稀缺"，两句话的关系没理清
3. **论证平行化**：三个分论点都是"最重要随境遇变"的同义反复，没有递进
4. **脱离当代青年实际**：只谈"是什么""为什么"，不落到"怎么办"、不落到我们高中生的具体处境
5. **堆砌金句**：开头"千江有水千江月"一句 + 中间"一花一世界"一句 + 结尾"不积跬步"一句，金句各说各话，不服务论证

### 六、下一步建议

选定立意后，可以对我说："**上面那道题，我选立意 X，帮我列提纲**"，我会按五句一段法给出完整提纲并配素材。
```

## 学生的追问 · 立意打磨

### 学生输入

> 老师，我想写立意 2 的变体：我想写"每个人都要找到自己的最重要，不要被别人的最重要绑架"，这样写行不行？

---

### Skill 输出（按 M2 · 立意打磨模式）

```markdown
## 立意诊断：你提出的立意

**你的立意**："每个人都要找到自己的最重要，不要被别人的最重要绑架"

### 诊断结果：⚠️ 部分扣题 + 方向偏移，需要调整

#### 优点

1. **有问题意识**：你抓住了"被绑架"这个现象，这是很真实的当代青年困境（父母的"最重要"、社会的"最重要"、同龄人的"最重要"都在裹挟个体）。
2. **有当代关怀**：能自然落到"怎么办"，对高中生而言有切身意义。

#### 问题

1. **只抓了材料的第 1 句**：题目两句话——"最重要随立场境遇而变"（第一句） + "反复宣称暴露稀缺"（第二句）。你的立意**完全绕开了第二句**。阅卷老师会判定为"材料要素丢失一半"，最高打到二类下（47–49 分）。
2. **方向偏离"优先级"**：材料谈的是"价值优先级的判断"，你的立意转向了"寻找自我的主体性"——这是另一个话题（"做自己"类），不是"最重要"类。
3. **辩证不足**：你的立意本身是一句结论——"要找到自己的"，缺少对"为什么会被绑架"、"什么时候应当听从他人的'最重要'"的讨论。直接起跳做结论，会显得浅。

#### 三条优化建议

1. **把两句材料都用上**：可以改为"**既要在流变中找到自己的最重要，也要警惕'被反复强调'的稀缺**"——这样两句话都在你的立意视野里。

2. **紧扣"优先级"这个具体概念**：你的立意里"最重要"应该明确指**优先级**，而不是"自我"。可以改为"**每个人应当根据自身阶段重新排列优先级，不必被他人的排序绑架**"。

3. **加上辩证**：立意里除了"不要被绑架"，还应承认"某些集体性的'最重要'（如家国、公德）是不该被'自己的最重要'取代的"。否则容易写成极端的个人主义。

#### 替代立意建议

如果你喜欢"不被绑架"这个核心感觉，我推荐两个改造后的立意：

**立意 A：执衡而行，不困于他人之"最重要"**

- 中心句：承认"最重要"的流变与立场相关性，但不等于"我的最重要就全由我说了算"——真正的成熟，是既不被他人绑架，也不走向另一极端的唯我。
- 分论点：
  1. 他人之"最重要"值得倾听——它是立场与境遇的经验
  2. 但不应被绑架——因为每个人的立场与境遇不同
  3. 破局在"辩证倾听"——择其扣合自身者而取之

**立意 B：在"最重要"的流变中守护真正属于自己的那一份**

- 中心句：与其在多方"最重要"的裹挟中迷失，不如借助"反复宣称暴露稀缺"这一洞察，识别出真正的"最重要"并以行动守护。
- 分论点：
  1. "最重要"的流变揭示其主观性，不必强求统一
  2. "反复宣称"提示：**被反复强调的，正是我们以为拥有实则缺少的**
  3. 作为青年，当以"行动"代替"强调"——不再空喊"健康最重要"而真的开始锻炼

### 下一步

你可以：
- 直接选替代立意 A 或 B
- 或告诉我你想保留原立意的哪些元素，我们再调一版
- 或说"**我选立意 A，帮我列提纲**"，进入提纲阶段
```

## 附录 · 这个示例展示了什么

本示例演示了 Skill 在审题与立意打磨时应当遵守的**六条纪律**：

1. **三叩审题法**全部走一遍——材料、提示语、试题
2. **关键概念具体化**——用表格展示"具体含义 vs 常见误解"
3. **立意三选一**——每个立意给出完整骨架 + 素材 + 难度评估
4. **陷阱清单**——针对本题、不是通用的
5. **诊断学生立意时要具体**——指出"第几句没扣""偏到哪个话题"
6. **给替代方案，不只否定**——帮学生保留他思路里的好东西

## 这个示例没展示（但 Skill 应做的）

- 如果学生问"立意 1 的第二个分论点我不会展开怎么办"，应当给出该分论点的**展开路径**（阐释方向 + 2-3 个候选素材 + 分析法选择）
- 如果学生说"我不喜欢这三个立意"，应当按三叩审题法**重新来一遍**，不是硬推原来的立意
