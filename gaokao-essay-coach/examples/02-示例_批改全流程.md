# 示例 · 批改全流程

> 这是一个完整的"学生交作文 → Skill 批改 → 学生问为什么扣这么多分 → Skill 复盘"的走查。
> 
> 展示批改的**分段评语格式**、"**遗憾的是**"句式、**具体修改建议**的写法。

---

## 对话样本

### 学生输入

> 老师，我按"在流变中守护永恒"这个立意写了一篇作文，你给我批改一下吧：
> 
> ---
> 
> **流变中的"最重要"**
> 
> 在我们的日常生活中，"最重要"这个词是经常被我们提起的。我们用它来确定事物的优先级。但是，"最重要"的判断会随着立场和境遇而改变，同时当人们反复强调某件事物"最重要"时，往往这件事物本身就是稀缺的。
> 
> 每个人对"最重要"的理解都是不一样的。比如说，对于学生来说，学习最重要；对于工人来说，工作最重要；对于父母来说，孩子最重要。这就是我们所说的立场不同。袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子的杂交水稻。钱学森觉得报效祖国最重要，所以他回国参加建设。所以说，立场不同，对"最重要"的看法也不同。
> 
> 另外，境遇也会影响我们对"最重要"的判断。苏轼本来觉得做官很重要，但是被贬之后他觉得自由和洒脱最重要，所以写了很多好文章。司马迁本来觉得出人头地最重要，但是受了宫刑之后觉得完成《史记》最重要。可见，境遇确实会改变我们的想法。
> 
> 但是，有一些"最重要"是永恒的，比如说爱国、诚信、善良，这些都是永远最重要的。我们要记住这些，才不会在这个复杂的社会里迷失自己。作为高中生，我们要好好学习，天天向上，要把学习当成现阶段最重要的事情，这样才能考上好的大学，将来为国家做贡献。
> 
> 总之，"最重要"虽然会变，但是我们要抓住那些永恒的东西，做好自己应该做的事情。这就是我对这道题的思考。

---

### Skill 输出（按 M5 · 批改评分模式）

```markdown
## 批改报告

### 总评

本文属议论类二类下文。能扣住"最重要随立场境遇而变"的第一层材料展开分析，素材选用有袁隆平、钱学森、苏轼、司马迁等，算合格的"安全卷"。**遗憾的是**，全文有三个硬伤：一是材料第二句"反复宣称暴露稀缺"几乎没有分析；二是段落结构没有递进，三段都在说"立场不同 / 境遇不同 / 最重要会变"，语义重复；三是语言平白，节点词缺失，没有议论文的骨气。

### 开头段评语

**原文**：
> 在我们的日常生活中，"最重要"这个词是经常被我们提起的。我们用它来确定事物的优先级。但是，"最重要"的判断会随着立场和境遇而改变，同时当人们反复强调某件事物"最重要"时，往往这件事物本身就是稀缺的。

你把材料的两句话基本复述了一遍，算是"引材料"到位，但**遗憾的是**，开头做了**三件事**——引材料、解释、再引材料——却**一件最重要的事没做**：**亮出中心观点**。阅卷老师读完你这段，根本不知道你这篇作文想证明什么。

**标题"流变中的'最重要'"**也偏弱——点到"流变"却没点到你的观点；建议改为**对仗式**标题，比如"**执一而应万：在流变中守护永恒**"或"**承认流变，锚定稀缺**"。

### 主体段评语

**主体段 1**（分论点：立场不同，对"最重要"的看法也不同）：

论点本身成立，举例有袁隆平与钱学森，素材扣题。**遗憾的是**：

1. **没按五句一段法**——你的段落是"观点 + 举例 1 + 举例 2 + 结论"，缺**阐释句**（立场为什么会影响"最重要"）、缺**分析句**（袁隆平和钱学森的选择如何证明你的论点）。
2. **素材叙述过于简略**——"袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子的杂交水稻"，这一句话把一个活生生的人物缩成了标签。要么展开讲（他在 1960 年代饥荒中立下"禾下乘凉梦"、从三系法到第三代杂交水稻…），要么不用。
3. **学生 / 工人 / 父母的例子抽象化了**——这是"空举例"，没有具体人物，没有说服力。建议删掉。

**主体段 2**（分论点：境遇会影响对"最重要"的判断）：

苏轼和司马迁的选择很贴切。**遗憾的是**：

1. **这一段和第一段没有递进**——都在说"X 会影响最重要的判断"。读者读完会觉得"你说了两遍同一件事"。
2. **完全没提材料第二句"反复宣称暴露稀缺"**——这是材料的另一半内容，你整篇作文都在绕开它，这在阅卷里会被判为"材料要素不全"，直接扣分。
3. **"可见，境遇确实会改变我们的想法"**这一句结论太弱，"确实""会"都是副词，没有力量。

**主体段 3**（分论点：有一些"最重要"是永恒的）：

这一段你开始触碰到"守住不变"的价值，方向是对的。**遗憾的是**：

1. **"爱国、诚信、善良"这样的大词**直接抛出来，没有论证、没有人物、没有材料支撑，是典型的"空喊口号"。
2. **"作为高中生…把学习当成现阶段最重要的事情"**——这个过渡太生硬，且"好好学习，天天向上，将来为国家做贡献"是**纯口号**，没有思想含量。阅卷老师见过千万遍。
3. **没有给出"怎么办"的具体路径**——只是说"要记住"，没说"怎么记住"。

### 结尾段评语

**原文**：
> 总之，"最重要"虽然会变，但是我们要抓住那些永恒的东西，做好自己应该做的事情。这就是我对这道题的思考。

**这个结尾基本等于放弃**。三句话完成了**复述中心观点 + 总结了什么都没总结 + 一句"这就是我的思考"**。

议论文结尾的三件事全部缺失：
- 没有**引一句**（诗词或名言）
- 没有**回扣开头**（没有和开头呼应）
- 没有**升华呼吁**（没有对时代 / 青年的呼吁）

### 语言与综合

**优点**：
1. 素材选择还算对路（袁隆平、钱学森、苏轼、司马迁都是本题可用素材）
2. 没有大的错别字或逻辑硬伤
3. 分论点方向基本正确

**遗憾的是**：
1. **节点词几乎为零**——全文没有一个"可见""遗憾的是""更主要的问题是""其实"这样的节点词。阅卷老师找不到你的思路轨迹。
2. **句式单调**——全文基本是陈述句，没有反问、没有假设、没有排比。"就是我们所说的立场不同""所以说立场不同…也不同"，这种重复句式读起来像初中生作文。
3. **空喊口号**——"好好学习，天天向上""将来为国家做贡献"这种话在议论文里是**减分项**。
4. **没有辩证性**——你只说"最重要会变"和"有些最重要是永恒的"，但没有解释**为什么这两者可以并存**。

### 评分：44 / 60

**等级**：二类下

**主要依据**：
- 内容立意 **12/20**：扣住第一句但丢失第二句材料要素，立意平直缺辩证
- 结构论证 **13/20**：三段无递进、主体段未按五句一段法、缺分析句
- 语言文采 **8/15**：句式单调、零节点词、空口号多
- 任务完成 **4/5**：字数达标、文体正确、但开头丢了"亮观点"

### 三条具体修改建议

1. **重写开头段**：在现在的基础上增加一句**亮观点**的话。建议的开头段：
   > "最重要"一词，常被我们用以确立事物的优先级。然而细察之下，这看似坚定的判断，却如流水般随立场与境遇变迁。更耐人寻味的是，当我们不断宣称某事物"最重要"时，恰恰暴露了它在现实中的稀缺与脆弱。**这二者之间的张力提醒我们：真正的智慧，不在于找到一个永恒不变的"最重要"，而在于在流变中锚定价值，在稀缺中用行动守护。**（加粗句是新增的中心观点句，字数控制在 150 字内）

2. **第二段改为按五句一段法**，并增加"反复宣称暴露稀缺"的分析（这是材料第二句！）。示例：
   > （观点）"最重要"的反复宣称，暴露的是其现实中的稀缺与脆弱。（阐释）稀缺催生重视，脆弱倒逼强调——我们高喊什么，往往恰恰因为缺少什么。（材料）林觉民在起义前夜写给陈意映的绝笔信中，反复倾诉"吾至爱汝"——正因为这爱太深、分离太痛，他才三次、五次地说出"最爱"。（分析）**倘若**这份爱早已安稳无虞，**又怎会**在信纸上反复泣血？（结论）可见，**反复宣称**从来不是坚固的证据，而是脆弱的自白。

3. **删掉口号，换成具体建议**：第三段的"作为高中生…把学习当成现阶段最重要的事情，这样才能考上好的大学，将来为国家做贡献"整段删掉，改为具体、有分析的建议。示例：
   > 作为青年，我们应以**行动填补语言的焦虑**。社会反复强调"诚信最重要"，与其空喊口号，不如从一次不抄袭的作业开始；反复强调"健康最重要"，与其把它挂在嘴边，不如每天多走十分钟。正如袁隆平从未说过"吃饭最重要"，却用一辈子让中国人不再挨饿；张桂梅从未挂过"教育最重要"的标语，却用布满膏药的手托起两千女孩的未来。**可见，真正的"最重要"，从不需要宣讲，它活在行动里。**

### 下一步

如果你按这三条建议改一版再发给我，我可以做第二轮评阅——按这思路改，这篇作文完全有机会冲到 50–53 分（二类上）。
```

## 学生的追问 · 为什么扣这么多分

### 学生输入

> 老师，我感觉我写的还可以啊，怎么才 44 分？我的素材不都用对了吗？

---

### Skill 输出

```markdown
我理解你觉得"不差"，但我们换个角度看——阅卷老师判断"作文好不好"的标准，**不是看你用了什么素材，而是看你怎么用**。

### 类比一下

你这篇作文，**像一堆好食材没炒成一道菜**：
- 袁隆平、钱学森、苏轼、司马迁，都是上好的食材
- 可你只是把它们**摆在盘子里**（"袁隆平觉得…所以他…"，一句话带过）
- 没有**炒**（没有分析句）、没有**调味**（没有节点词）、没有**摆盘**（没有对仗结构）

所以阅卷老师看到的是——"这学生知道考题要用袁隆平，但不知道**为什么**用、**怎么**用"。

### 高分作文的关键不在素材，在"论证动作"

对比一下，同样用袁隆平这个素材：

**你的写法（说明式）**：
> 袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子的杂交水稻。

**一类文的写法（论证式）**：
> **君不见**袁隆平以"禾下乘凉梦"为动力，从 1960 年代的饥荒中立下志向，历经三系法、两系法、第三代杂交水稻的一次次失败与突破——**若没有**"让中国人吃饱饭"这个稀缺年代最真切的呼声，**又怎会有**他六十年如一日躬耕稻田的坚持？**这份将个人命运与一国温饱绑定的选择，正是"最重要"在他立场中的具象化。**

看到区别了吗？
- 有"**君不见**"的节点词
- 有具体的时代细节（1960 年代饥荒）
- 有"**若没有…又怎会有…**"的假设分析
- 有对论点的回扣（"最重要在他立场中的具象化"）

### 分数对照表

| 你的动作 | 效果 |
|---|---|
| 引了材料 | 任务完成分 ✓ |
| 用了对路素材 | 内容分部分完成 ✓ |
| 没写分析句 | 结构分丢失 ✗ |
| 没用节点词 | 语言分丢失 ✗ |
| 空喊"好好学习"口号 | 内容分倒扣 ✗ |
| 结尾没引一句 / 没回扣 / 没呼吁 | 结构 + 语言双扣 ✗ |

这就是 44 分的来源。不是你素材不对，是你**没把素材做成论证**。

### 好消息

你的**底子不差**——选得对素材、扣得住题眼、段落分清了——这些是上到二类文必需的东西，很多学生三类文都做不到。

你现在需要的训练，**不是换素材、不是背新的金句**，而是：
1. 背下"五句一段法"的五个句子功能
2. 练"节点词"的使用（每段至少 2 个）
3. 练"假设分析"（倘若…又怎能…）和"评价分析"（此等…非…所能）

按那三条建议改一版，发给我。
```

## 附录 · 这个示例展示了什么

本示例演示了 Skill 在批改作文时应当遵守的**七条纪律**：

1. **先总评定位**——二类下，并说清为什么是这个档次
2. **分段评语**——开头 / 每个主体段 / 结尾 / 语言综合，逐段点评
3. **"遗憾的是"句式**——作为指出问题的标准起手
4. **四维度打分**——内容立意 / 结构论证 / 语言文采 / 任务完成，各有依据
5. **三条具体修改建议**——每条都指明段落 + 给出示例句
6. **不只否定还给改法**——删掉口号但给出"改成什么"
7. **尊重学生情绪**——当学生反驳时，不是重复扣分理由，而是用类比（"一堆好食材没炒成菜"）帮他理解，最后给出好消息与明确训练路径

## 这个示例没展示（但 Skill 应做的）

- 学生作文**严重跑题**时，应直接指出"这篇基本脱题，建议重写"，不是硬打分数
- 学生作文**有严重错别字**（3 个以上）时，应当单独列出并说明扣分规则
- 学生作文**有明显套作痕迹**（开头是网传万能模板）时，应指出并教他如何避免
- 学生发来的是**记叙文**时，应当说明"本 Skill 侧重议论文"并给出记叙文的基本反馈，不按议论文标准打分
