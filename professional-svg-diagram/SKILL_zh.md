# 专业 SVG 汇报图

## 目标

创建可编辑、可直接用于管理层汇报的 SVG。成品应具有清晰的阅读路径、克制的语义色彩、简洁标签，以及足以支撑口头讲解的上下文。保留用户来源材料中已经确认的术语和事实。

如果用户明确要求先提供 Markdown 或 Mermaid，先生成中间产物，在结构得到确认后转换为 SVG；如果用户在同一请求中同时要求两种产物，则可以在同一轮完成。不要用 Mermaid 替代用户要求的 SVG。

## 先选择布局

绘制前先识别信息结构。只有匹配时才使用对应模板，不要为了套用模板而扭曲内容。

| 信息结构 | 推荐布局 | 起始资源 |
| --- | --- | --- |
| 来源、处理、输出或堆叠依赖 | 分层流程 | `assets/report-diagram-template.svg` |
| 跨系统的职责或执行上下文 | 泳道 | `assets/swimlane-template.svg` |
| 分阶段交付、成熟度或发布计划 | 时间线 | `assets/timeline-template.svg` |
| 能力、优先级或权衡关系 | 矩阵 | `assets/matrix-template.svg` |
| 规则、路由、校验或回退 | 决策流程 | `assets/decision-flow-template.svg` |

对于分栏对比、垂直主线和中心辐射结构，可以改造最接近的模板，也可以创建专用布局。只有当上、中、下结构能真实表达依赖关系时，才使用三层架构。

## 视觉体系

- 根据内容选择画布。幻灯片式摘要使用 `1920x1080`，较深流程使用 `1920x1280` 到 `1920x1600`。只有阅读路径确实受益时才使用更宽或更高的画布。
- 使用白色页面背景、浅色分区、细边框，以及 `rx=10` 到 `14` 的卡片。
- 使用 `Inter, PingFang SC, Microsoft YaHei, Arial, sans-serif`，并保留可编辑文字。
- 统一使用语义色彩：依赖和基础设施使用灰蓝或蓝色，主动处理使用橙色，检索或能力执行使用绿色，结果组装或未来能力使用粉色。
- 不要只依赖颜色传递含义，应同时使用标签、位置、边框样式或连线样式。
- 避免渐变、装饰色块、插画和重阴影。最多定义一种轻量阴影。
- 中文请求优先使用中文标签，同时保留技术术语、API 名称和缩写。来源产物使用繁体中文时继续使用繁体中文，除非用户另有要求。

## 文字与几何

- 每张卡片应说明该组件解决什么问题，语言层次与目标受众匹配。
- 在可行时，标题不超过 12 个汉字，正文每行不超过 22 个汉字。
- 使用显式 `<tspan>` 分行，不依赖 SVG 自动换行或 `foreignObject`。
- 卡片水平内边距至少 24 px，垂直内边距至少 18 px。在宽度为 1920 的画布上，正文字号不小于 13 px，标题字号不小于 16 px。
- 如果文字无法放入两到三行，应增大卡片或精简措辞，不要单独把标签缩小到最小字号以下。
- 重复卡片应对齐并保持等高，除非层级关系确实需要明显差异。
- 除非用户要求实现视图，否则避免内部类名、枚举名和代码级细节。

## 连线

- 默认只绘制主流程。连线用于说明阅读顺序，而不是罗列所有依赖。
- 使用短水平线、垂直线或正交折线绕开卡片，不要穿过文字或节点。
- 当连线成为长对角线或出现多次交叉时，重新考虑布局。
- 不要把能力清单连接成处理步骤。依赖清单应使用虚线边框或小型依赖标签。
- 箭头标记应位于 viewBox 内，并保持一致的标记尺寸和线宽。

## 工作流程

1. 确定图表类型、受众、事实来源和自然阅读路径。
2. 在陈述项目事实或编辑现有产物前，检查相关代码、文档、已确认图表或 SVG 节点。
3. 选择匹配的起始资源；没有合适模板时创建专用布局。
4. 编写 SVG，使用清晰的 `<defs>`、一个 `<title>`、一个 `<desc>`、分组区块、可编辑文字和明确连线。
5. 准确保留用户修正，后续迭代只修改用户要求的内容或布局。
6. 使用内置检查器验证：

```bash
python3 scripts/validate_svg.py path/to/diagram.svg
```

7. 将 SVG 渲染为 PNG 或在浏览器中打开。在演示尺寸下检查完整画布，确认没有裁切、重叠、不可读文字、错误字体回退、连线碰撞或含糊的阅读顺序。仅通过 XML 校验并不充分。

## 交付

- 交付可编辑的 `.svg`；渲染器可用或用户要求时，同时提供 `.png` 预览。
- 所有可见内容都必须位于 viewBox 内，包括箭头和阴影。
- 除非项目已有命名规范，否则使用具有描述性的英文小写连字符文件名。
- 报告输出路径和已执行的验证。如果无法完成视觉渲染，应明确说明。
