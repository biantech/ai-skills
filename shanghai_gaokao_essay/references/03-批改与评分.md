# 批改与评分

> 改作文的本事，比写作文更难。一篇作文的毛病在哪，往往要读三遍才看得透。
> 
> Skill 在批改时要做的不是"打个分就走"，而是：先读懂学生想说什么，再指出他说没说清楚，最后告诉他怎么改。

> **上海版适配说明** ：本文件移植自通用高考作文教练资料。上海高考作文按 70 分制评价，实际批改时使用下方“上海 70 分制参考档次”；文中保留的旧版示例分数和通用评语只用于展示批改动作。下方分数区间是训练用近似档次，不是上海官方公布的机械分档，也不是官方阅卷结论。

本文件是 Skill 执行批改评分（M5） 模式时的评分标准与评语范式。

---

## 一、上海 70 分制参考档次

### 等级划分

| 分数段 | 等级 | 描述 |
|---|---|---|
| 63–70 | 一类文 | 立意深刻 + 结构严密 + 语言有个性 + 思想成熟 |
| 52–62 | 二类文 | 扣紧材料 + 结构清晰 + 语言通顺 + 有亮点 |
| 39–51 | 三类文 | 基本完成任务，但立意、结构或语言仍有明显提升空间 |
| 21–38 | 四类文 | 立意偏离或结构、语言问题较多，任务完成度不足 |
| 0–20 | 五类文 | 跑题、套作、抄袭、严重缺字或其他严重问题 |

### 报告中的六方面分析

文章分析或批改报告须在总评后设置独立的“六方面分析”章节，按以下顺序设置六个子节，不以逐段评语或一张汇总表替代。六方面用于文本诊断和修改指导，不是六项相加的机械计分表。

| 子节 | 分析关注点 |
|---|---|
| 1. 审题立意 | 是否回应材料与任务，是否抓住核心关系，中心论点是否明确、切题且可论证 |
| 2. 思辨逻辑 | 理由能否支撑结论，是否有因果跳跃、自相矛盾或绝对判断，是否考虑条件、反例与边界 |
| 3. 概念界定 | 关键词在题目语境中的含义是否清楚，是否区分相近概念，前后是否一致，有无概念偷换 |
| 4. 论证层次 | 分论点和段落如何递进、转折或深化，材料与分析是否形成论证，是否重复或比例失衡 |
| 5. 现实关照 | 是否联系具体个人处境、公共生活或时代问题，现实场景是否参与论证，判断是否有依据且避免口号化 |
| 6. 素材与文采 | 人物、事实、引语和出处是否可靠，素材是否切合观点，语言是否准确自然，修辞是否服务于说理 |

每个子节都结合原文段落编号或短句，写出已有优点、问题及影响、具体修改建议，必要时提供改写示例。有修改稿时补充对应调整。若无明显问题，说明依据及可进一步提升的方向；原题或材料缺失时，明确相应判断的限制，不猜测缺失内容。字数、文体等任务完成情况可在审题立意或阅读依据中说明。

### 加分与扣分项

加分（在等级基础上 +2）：
- 标题极佳（对仗工整且有新意）
- 有独到的思辨（超出一般立意）
- 素材选择独特且分析到位

训练中的风险提示（不要机械相加）：
- 标题平庸（"论 XXX"）
- 错别字 3 个以上（每个 -1，上限 -5）
- 段落比例严重失衡（开头占 200 字以上 / 主体段 <150 字）
- 出现"老师常说""我看过一本书"等过于口语化表达

## 二、一类卷质量检查

以下项目用于判断文章是否具备一类卷潜力，不是逐项扣分表，也没有“缺一项就不能超过某分”的硬性规则：

- [ ] 立意扣住材料的深层内涵，而不是替换成泛泛的励志话题
- [ ] 至少一处论证展现概念辨析、条件限制或辩证思考
- [ ] 段落之间有推进关系，主体段完成观点、材料、分析和小结等必要功能
- [ ] 素材准确、适量，并且解释了它如何支持观点
- [ ] 标题、开头和结尾共同服务于中心论点
- [ ] 有具体的现实关照，但不强制写青年口号或家国表达
- [ ] 语言准确自然，引用和修辞不喧宾夺主

## 三、二类文与三类文的分野

**二类文与三类文的分野** ：

- 二类文：基本扣题，结构和论证能够支撑中心观点，语言与任务完成度总体稳定
- 三类文：有擦边、局部偏题、论证推进不足或素材与观点咬合不紧

**较低档次的典型特征** ：

- 立意偏离材料核心
- 分论点关系混乱（三个分论点其实是一个分论点的三种说法）
- 大量空话、没有具体分析
- 素材堆砌不分析

## 四、分段评语范式

生成报告时，先写总评和独立的“六方面分析”章节，再按需补充分段评语。以下是分段评语的写法，完整报告结构见第五节。

### 1. 总评（先扣总体特征）

一句话定位：
- "本文属议论类一类文 / 二类上 / 二类下 ..."
- 点出最突出的特色或最大的问题

**示例** ：

> 本文属议论类一类文。紧扣"听完整话，做明白事"的核心，以古语、熟语后半句"常被忽略"的文化现象为切入点，层层深入地建构"听完整话—培养思辨智慧—做明白事"的逻辑链条，立意高远且贴合现实。

### 2. 开头段评语

**关注点** ：

- 引材料是否简洁（不超过 50 字）
- 是否及时亮出中心观点
- 有没有引发阅读兴趣

**三种评法** ：

- 到位型：「开篇 XX 地切入话题，迅速亮出核心观点，奠定全文基调。」
- 有问题型：「 **遗憾的是** ，开头复述材料占了 XX 字，留给论证的空间被压缩。」
- 需重写型：「开头没有亮出中心观点，读者看到主体段才知道你要谈什么，这在高考里会吃亏。」

### 3. 主体段逐段评语

每段按以下顺序点评：

```markdown
**主体段 X** （分论点：[摘抄段首]）：

[先肯定：论点清晰 / 材料贴切 / 分析到位]

[指出结构：是否符合五句一段法？哪一句缺失或偏弱？]

[指出素材：是否扣观点？是否有多样性？]

**遗憾的是** ，[具体指出一个问题，并说明如何改进]。
```

**示例** ：

> **主体段 2** （分论点：坚守更是超越个人得失的家国情怀）：
>
> 论点清晰，以"家国情怀"把前段的"承诺责任"做了升华，层次分明。三个素材（保定学院西部支教群体、栾恩杰、陆鸿）都紧扣"超越个人得失"的核心，排比感也出来了。
>
> **遗憾的是** ，分析句稍显薄弱——材料讲完直接跳到结论句，中间缺一个"为什么这些人能做到超越个人得失"的追问。建议在分析句加一句："究其缘由，他们都把小我的人生坐标，调校到了国家需要的经纬线上。"

### 4. 结尾段评语

**关注点** ：

- 是否回扣开头
- 是否有对青年的呼吁
- 是否有升华（而非重复中心观点）

### 5. 语言综合评语

把全篇的语言问题合在一起点评：

```markdown
**语言与综合** ：

**优点** ：

1. [具体一条，如：节点语言运用娴熟，"可见""遗憾的是"推进有力]
2. [如：开头"XX 像 YY"的比喻新颖]

**遗憾的是** ：

1. [具体一条，如：第二段"我们要坚持"三字重复三次，可换成"我们应当笃行/笃守/笃志"]
2. [如：引用"不积跬步无以至千里"过于常见，可换成更贴近话题的一句]
```

### 6. 评分（仅在用户要求时）

```markdown
### 评分：[XX] / 70（训练参考）

**等级** ：[一类文 / 二类文 / 三类文 / ...]

**主要依据** ：

- 审题与立意：[简评]
- 结构与论证：[简评]
- 语言与表达：[简评]
- 任务完成：[简评]
```

### 7. 三条具体修改建议

这是最重要的一步。 **不能说空话** 。每条建议都要：
- 指明改哪一段的哪一句
- 给出具体的改法示例

**不合格建议** ：

- "加强文采" ❌
- "论证再深入一些" ❌
- "多用一些好的素材" ❌

**合格建议** ：

- "第二段'我们要坚持'三字重复，可改为：'我们应当笃守而非执着，笃行而非盲从。'" ✅
- "第三段缺一个当代青年的素材。可加入庞众望（父亲精神分裂、母亲截肢，他以 684 分考入清华）作为与前文张桂梅并列的素材。" ✅
- "结尾引用换成《论语》'士不可以不弘毅，任重而道远'，比现用的'宝剑锋从磨砺出'更扣'担当'主题。" ✅

## 五、完整批改输出模板（Skill 在 M5 模式下使用）

以下六个子节均需保留并结合当篇文章展开，不能只复制标题或通用评语。随后设置“最需要改进的5～6个问题”章节，按影响程度归纳不同问题，每项给出原文依据、影响和改法，有修改稿时说明对应调整；实际问题不足5个时如实说明，不制造或重复拆分问题。分段点评按实际段落数量安排；评分部分仅在用户要求时输出。

[已有优点及原文依据；推理、条件或反例的问题及影响；具体修改建议；有修改稿时说明对应调整]

[已有优点及原文依据；概念含义、区分或一致性的问题及影响；具体修改建议；有修改稿时说明对应调整]

## 六、批改时的注意事项

### 1. 不要全程只说好话

一味夸奖对学生没有帮助。即使是一类文，也一定能挑出 1–2 条可以提升的点。

### 2. 不要全程只挑毛病

即使是三类下的作文，也要找到 1–2 个亮点（哪怕只是一个用得不错的词）给予肯定。否定式反馈会让学生失去信心。

### 3. " **遗憾的是** "是关键句式

当指出问题时，用" **遗憾的是** "这个节点词引出——既给出批评，又留有余地，是老师的成熟评语风格。

### 4. 不用模糊评语

禁止这类话：
- "语言还不够流畅"（不流畅到什么程度？）
- "论证还要加强"（怎么加强？）
- "素材选择有待改进"（改进成什么样？）

必须落到具体字句：
- "第二段'..."这一句，语序可调为'...'，更符合议论文节奏"
- "'举世皆浊我独清'引用与'集体主义'主题不符，换成'天下兴亡，匹夫有责'更贴切"

### 5. 不要只改不教

改完后，学生要知道 **为什么这样改** ——建议里要包含"这样改是因为..."的解释。

### 6. 涉及具体人物时，先查库

如果学生用了人物素材，Skill 要对照 `resources/01-人物素材库.md` 检查：
- 事迹是否准确？
- 人物与观点是否吻合？
- 如果库里没有，标注"该人物事迹 Skill 库未收录，请自行核对"

### 7. 分数要诚实

不要为了鼓励学生给虚高分数。 **给的分要经得起真实高考阅卷的检验** 。

### 8. 对学生的态度

像一位严厉但温暖的真老师：
- 不说教（"你要知道作文是..."）
- 不说假话（"这篇写得非常棒！"）
- 不夹生硬的 AI 话术（"让我们一起来看看..."）
- 说人话，直接，但留有鼓励

## 七、特殊情况处理

### 情况 A：学生给的是半篇作文

如果只有开头段或前两段：
- 评已写部分
- 指出接下来每段应该做什么
- 不要强行评估整体

### 情况 B：学生给的是记叙文 / 散文

本 Skill 是议论文训练体系。如果学生发来记叙文：
- 说明："本 Skill 更擅长议论文批改。你这篇是记叙文，我可以就结构和语言给建议，但不按议论文评分标准打分。"
- 给基本的结构和语言反馈
- 建议学生发议论文来练

### 情况 C：严重偏题

如果学生作文与材料几乎无关：
- 先明确指出偏题（不绕弯子）
- 回到材料，帮他重新审一遍题
- 建议重写或按原立意大改

### 情况 D：严重抄袭 / 套作

如果识别出明显套作痕迹：
- 指出："这段开头在若干范文里出现过，阅卷老师能识别出套作，会重扣分。"
- 教学生如何避免套作（每道题独立审题）

## 八、评语中的语气示范

**好的评语语气** （直接、具体、有温度）：

> 本文开头"千江有水千江月，每个人的'最重要'或许不同"这句引用用得很灵气，一下子把话题的流变性点出来了。主体段三个分论点层层递进，从个体立场到家国担当，思路完整。 **遗憾的是** ，第三段在谈家国情怀时，只用了钱七虎、沈忠芳两个素材，都偏军工背景，可以考虑加入一位教育或医疗领域的人物（比如张桂梅或吴孟超），让"家国"的外延更丰富。

**不好的评语语气** （AI 味、说教、空）：

> 这篇作文写得很好！你的立意很深刻，让我们一起来看看：开头写得不错，中间也很精彩，结尾升华了主题。作为一个高中生能写出这样的文章是非常不容易的！继续加油！

对比即可看出：前者像老师，后者像客服。
